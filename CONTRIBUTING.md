# Contributing

Changes should state the observed problem, exact hardware/source version, proposed behavior and validation evidence. For control changes include voltage, surface/load, geometry, sample interval and before/after measurements. For ROS changes include startup command, message units, topic/TF ownership and serial reader topology.

Historical experiments are preserved with original filenames and source. Add an explicitly described revision rather than silently presenting retuned code as the version used in an older video. Keep source implementation, owner-reported testing and independently measured performance distinguishable.

Use the bug and experiment issue templates. Proposed SLAM/navigation work belongs on the roadmap until it has reproducible evidence.
